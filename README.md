# SignalForge
Data-science / ML engineering portfolio project.

Run: open `index.html`.

Purpose:
A small model-observability console showing rolling accuracy, feature population drift (PSI-style signal), latency, configurable alerts, and an injected distribution shift.

The telemetry is synthetic. This is intentionally a monitoring/engineering project rather than a generative-AI demo.

Good interview topics:
model drift, data drift vs performance drift, monitoring thresholds, delayed labels, alert fatigue, production telemetry.
